# Редакция Enterprise

LookSee поставляется одним набором образов с двумя редакциями. Редакция
Community — это код за пределами каталога `ee/` репозитория, лицензированный
под Apache-2.0. Редакция Enterprise — это код внутри `ee/`, лицензированный
под [лицензией LookSee Enterprise](https://github.com/okoflow/looksee/blob/main/ee/LICENSE)
и разблокируемый лицензионным ключом.

## Возможности

| Возможность | Узлы | Что добавляет |
| --- | --- | --- |
| Фильтры измерений | Count, Line crossing, Dwell | Подсчёт объектов внутри зоны относительно порога, подсчёт пересечений линии с учётом направления и обнаружение объектов, которые остаются в зоне дольше заданного предела. Все три опираются на трекинг объектов между кадрами. |
| Интеграции Enterprise | Slack | Сообщения во входящий вебхук Slack с теми же шаблонами, что и у остальных действий обмена сообщениями. |

В редакции Community эти узлы показаны в палитре с замком, и их нельзя
перетащить на холст. Рабочий процесс, содержащий один из них, например после
импорта графа через API, отклоняется при **Run** с кодом ошибки
`feature_not_licensed` и статусом HTTP 402.

## Включение

Задайте ключ в `.env` и перезапустите API:

```bash
LICENSE_KEY=<your key>
```

```bash
docker compose up -d api
```

`GET /entitlements` сообщает активную редакцию и возможности:

```json
{ "edition": "enterprise", "features": ["measurement_filters", "enterprise_integrations"] }
```

Studio читает ту же конечную точку и разблокирует палитру. Рабочие процессы,
сохранённые с узлами Enterprise, начинают работать при следующем **Run**.

## Условия лицензирования

Лицензия Enterprise разрешает копировать и изменять код для разработки и
тестирования без подписки. Продуктивное использование требует действующей
лицензии на соответствующее число мест. Вклад в `ee/` принимается под той же
лицензией, как описано в
[CONTRIBUTING.md](https://github.com/okoflow/looksee/blob/main/CONTRIBUTING.md)
репозитория.
