# Узлы

Справочник по каждому узлу редактора рабочих процессов: что он делает, его
поля со значениями по умолчанию и ограничениями и что проверяет валидация при
**Run**. Имена полей в стиле кода — это ключи, используемые в API; инспектор
показывает их с более понятными подписями.

## Соединения

- У **Camera** один выход, и она соединяется ровно с одним **Detect**.
- **Detect** соединяется с любым числом фильтров и действий.
- У каждого фильтра два выхода, **If** и **Else**. Прошедшее событие уходит
  через **If**, не прошедшее — через **Else**. Связь без ветки считается
  **If**.
- **Snapshot** соединяется дальше с другими действиями, которые в этом случае
  получают снимок. У остальных действий выхода нет.
- Каждый узел выполняется не более одного раза на событие.

Палитра группирует узлы в разделы Sources, Detection, Logic, Object, Spatial,
Temporal и Actions. Узлы Enterprise (Count, Line crossing, Dwell, Slack)
показаны с замком, пока не настроен лицензионный ключ.

## Источники

### Camera — `camera_source`

| Поле | По умолчанию | Ограничения | Значение |
| --- | --- | --- | --- |
| `name` | `Camera` | от 1 до 128 символов | **Name**. Показывается в мониторе и в сообщениях оповещений |
| `source_type` | `rtsp` | `rtsp`, `rtmp`, `srt`, `webrtc`, `whep`, `file` | **Source**. Как MediaMTX принимает поток; см. [Камеры](cameras.md) |
| `url` | пусто | до 2048 символов | **URL**. URL потока для забираемых источников, ключ файла для `file`; не используется для `webrtc` |

При **Run** URL должен соответствовать типу источника: `rtsp://` или
`rtsps://` для RTSP, `rtmp://` или `rtmps://` для RTMP, `srt://` для SRT,
`http://`, `https://`, `whep://` или `wheps://` для WHEP и ключ файла из
букв, цифр, `.`, `_`, `-` и `/` для File.

## Детекция

### Detect — `detect`

| Поле | По умолчанию | Ограничения | Значение |
| --- | --- | --- | --- |
| `model_id` | нет | модель из `models/` | **Model**. Обязательна при **Run**. |
| `event_kinds` | все | до 64 типов, которые производит модель | **Events**. Пустое значение пропускает все типы событий модели. |
| `confidence_threshold` | `0.5` | от 0 до 1 | **Confidence**. Детекции ниже порога отбрасываются до трекинга. |
| `inference_fps` | `1` | от 1 до 15 | **Checks per second**. Как часто модель запускается на этой камере. |

Выбор модели в Studio подставляет её рекомендуемую уверенность.

## Фильтры

Фильтр пропускает или отклоняет каждое событие. Фильтры, которые проверяют
детекции, пропускают событие без детекций, если не указано иное.

### If / Else — `if_else_filter`

Сравнивает одно свойство события. Объект `condition` выбирает свойство полем
`field`:

| `field` | `operator` | `value` | Проходит, когда |
| --- | --- | --- | --- |
| `event_kind` | `is`, `is_not` | тип события | Тип события совпадает (или не совпадает) |
| `object_class` | `contains`, `not_contains` | метка, до 256 символов | Детекция с этой меткой присутствует (или отсутствует) |
| `detection_count` | `eq`, `neq`, `gt`, `gte`, `lt`, `lte` | от 0 до 1000, по умолчанию `gte 1` | Число детекций удовлетворяет выбранному сравнению |
| `max_confidence` | те же шесть операторов | от 0 до 1, по умолчанию `gte 0.5` | Наибольшая уверенность удовлетворяет выбранному сравнению |

При **Run** для `event_kind` и `object_class` нужно значение, и оно должно
быть одним из тех, что может произвести вышестоящая модель.

### Class — `class_filter`

| Поле | По умолчанию | Ограничения | Проходит, когда |
| --- | --- | --- | --- |
| `classes` | пусто | до 64 меток | Хотя бы одна детекция имеет одну из меток. Пустое значение пропускает всё. |

Метки должны принадлежать вышестоящей модели.

### Size — `size_filter`

| Поле | По умолчанию | Ограничения | Проходит, когда |
| --- | --- | --- | --- |
| `min_area` | `0` | от 0 до 1 | Рамка хотя бы одной детекции занимает не менее этой доли кадра… |
| `max_area` | `1` | от 0 до 1, не меньше `min_area` | …и не более этой доли |

Полезен, чтобы игнорировать далёкие объекты или ложные детекции размером в
несколько пикселей.

### Zone — `zone_filter`

| Поле | По умолчанию | Ограничения | Проходит, когда |
| --- | --- | --- | --- |
| `polygon` | пусто | от 3 до 100 точек, координаты от 0 до 1 относительно кадра | Центр рамки хотя бы одной детекции лежит внутри многоугольника |

Нарисуйте многоугольник в инспекторе или на живом кадре через
**Edit on preview**. При **Run** многоугольнику нужно не менее трёх точек.

### Schedule — `time_window_filter`

| Поле | По умолчанию | Ограничения | Значение |
| --- | --- | --- | --- |
| `start_hour` | `0` | от 0 до 23 | **Start hour**, включительно |
| `end_hour` | `23` | от 0 до 23 | **End hour**, включительно; значение меньше `start_hour` переносит окно через полночь |
| `weekdays` | с понедельника по пятницу | от 0 (понедельник) до 6 (воскресенье), при **Run** хотя бы один | **Weekdays** — дни недели, к которым применяется окно |
| `invert` | выключено | | **Outside schedule**: пропускать события вне окна, для сценариев нерабочего времени |

Время вычисляется в `EVENT_TIMEZONE`.

### Debounce — `debounce_filter`

| Поле | По умолчанию | Ограничения | Значение |
| --- | --- | --- | --- |
| `seconds` | `30` | от 1 до 3600 | После прохождения события последующие события с той же камеры отклоняются в течение этого времени |

Окно хранится отдельно для каждого узла и каждой камеры, поэтому несколько
узлов Debounce в одном рабочем процессе независимы.

### Count — `count_threshold_filter` (Enterprise)

| Поле | По умолчанию | Ограничения | Проходит, когда |
| --- | --- | --- | --- |
| `polygon` | пусто | до 100 точек; меньше 3 — считается весь кадр | |
| `operator` | `gte` | `gte`, `lte` | Число детекций внутри многоугольника не меньше (или не больше)… |
| `count` | `1` | от 0 до 1000 | …этого значения |

### Line crossing — `line_crossing_filter` (Enterprise)

| Поле | По умолчанию | Ограничения | Проходит, когда |
| --- | --- | --- | --- |
| `line` | пусто | ровно 2 точки при **Run** | Центр отслеживаемого объекта перешёл с одной стороны линии на другую с предыдущей проверки |
| `direction` | `any` | `any`, `in`, `out` | `in` считает пересечения с левой стороны линии на правую, если смотреть от первой точки ко второй; `out` — в обратном направлении |

Опирается на идентификаторы трекинга; для быстрых объектов повышайте
**Checks per second**.

### Dwell — `dwell_filter` (Enterprise)

| Поле | По умолчанию | Ограничения | Проходит, когда |
| --- | --- | --- | --- |
| `polygon` | пусто | от 3 до 100 точек | |
| `min_seconds` | `60` | от 1 до 3600 | Отслеживаемый объект пробыл внутри многоугольника не меньше этого времени |

описывает каждую интеграцию.

## Ограничения

Граф вмещает до 200 узлов, 400 связей и 100 комментариев. Идентификаторы
узлов — до 128 символов, идентификаторы связей — до 256.

## Валидация

Сохранение графа проверяет его структуру. **Run** дополнительно проверяет,
что каждый узел может выполняться. Studio выделяет узел, к которому относится
ошибка; API возвращает код в поле `code` со статусом 422 или 402 для ошибки
лицензирования.

| Код | Значение |
| --- | --- |
| `duplicate_node_ids`, `duplicate_edge_id` | Два узла или две связи имеют один идентификатор |
| `edge_node_missing` | Связь указывает на несуществующий узел |
| `branch_on_non_filter` | У связи есть ветка If/Else, но она выходит из узла, который не является фильтром |
| `no_camera_source` | В рабочем процессе нет Camera |
| `graph_cycle` | Связи образуют цикл |
| `node_not_runnable` | Обязательное поле пусто или некорректно; сообщение называет поле |
| `feature_not_licensed` | Узел Enterprise без лицензионного ключа (статус 402) |
| `detect_node_missing`, `multiple_detect_nodes` | Camera не достигает ни одного Detect или достигает больше одного |
| `model_not_selected`, `model_unavailable` | У Detect нет модели, или его модели нет в `models/` |
| `unsupported_event_kinds` | Detect выбирает события, которые модель не производит |
| `unsupported_classes` | Фильтр Class называет метки, которые вышестоящая модель не производит |
| `unsupported_condition_event`, `unsupported_condition_class` | Условие If / Else называет событие или метку, которые вышестоящая модель не производит |
| `asset_store_not_configured`, `asset_unavailable` | Камера File без библиотеки файлов или с отсутствующим объектом |
| `credential_unavailable`, `credential_type_mismatch` | Учётные данные действия отсутствуют или имеют другой тип |

Узлы, которых не достигает ни одна Camera, допускаются и игнорируются во
время выполнения; Studio помечает их предупреждением.
